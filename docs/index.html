Fronius-Display

Firmware für die Elecrow CrowPanels 5" und 7" – direkt im Browser flashen

  1. Display per USB-C mit dem Rechner verbinden.
  2. Diese Seite in Chrome oder Edge öffnen (Firefox und Safari können kein USB).
  3. Auf Installieren klicken und den Anschluss des Displays wählen.
  4. Unten den Knopf für deine Displaygröße wählen, Anschluss auswählen.

Die Größe steht auf der Rückseite der Platine: SKU DIS07050H = 5", SKU DIS08070H = 7". Die Firmware des einen läuft nicht auf dem anderen (Bild bleibt schwarz oder gestört – dann einfach mit der richtigen neu flashen).

7"

Startet die Verbindung nicht: am Display BOOT gedrückt halten, kurz RESET drücken, BOOT loslassen.

Nach dem Flashen

Das Display öffnet die Einstellungen von selbst. WLAN suchen und Passwort eingeben, dann im Reiter „Fronius“ die IP des Wechselrichters, die PV-Leistung (kWp) und die Batteriegröße (kWh) eintragen. Später erreichst du die Einstellungen über das Zahnrad oben links.

Am Wechselrichter muss die Solar API eingeschaltet sein (Webinterface → Kommunikation).

Beim Aktualisieren fragt das Tool, ob das Gerät gelöscht werden soll. Mit „Nein“ bleiben die Einstellungen erhalten.

Kein offizielles Produkt von Fronius. Nutzung auf eigene Gefahr. Quellcode und Anleitung: github.com/AlPi-BRV/fronius-display
